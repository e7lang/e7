# Code of conduct

Be kind, be constructive, assume good intent. Harassment, personal attacks and discriminatory language are
not accepted in issues, pull requests, discussions or any other project space.

Maintainers may edit or remove comments and block participants who don't follow this. To report a problem
privately, use [GitHub's reporting tools](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
or contact the maintainers of the e7lang organization.

This code is adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/).
